# kifu_player — PSV / tournament JSONL / CSA 棋譜プレイヤー TUI

PSV (PackedSfenValue) ファイル、`tournament` の出力 JSONL、CSA 棋譜を、同じ TUI で
1 手ずつ再生・閲覧するツール。対局が数千局規模になっても、横断した対局リストを
入力しながら絞り込んで目的の対局へすぐ辿り着ける。

読み取り専用のビューアで、棋譜ファイルの編集・変換は行わない。

## ビルド

対話的 TUI 用の依存（`ratatui`/`crossterm`）を default feature に含めていないため、
`kifu-player` feature を有効にしてビルドする。

```bash
cargo build -p tools --release --features kifu-player --bin kifu_player
```

## 使い方

`--psv` / `--tournament-dir` / `--csa` のいずれか 1 つを指定する（同時指定はできない）。

### PSV を開く

```bash
cargo run -p tools --release --features kifu-player --bin kifu_player -- \
  --psv runs/gensfen/<run>/gensfen.psv
```

`--psv` には**連続した自己対局ストリーム**（`gensfen` の直接出力等）を渡す。
`shuffle_psv`/`merge_psv` 等でレコード順がシャッフルされたプールを渡すと対局の区切りを
正しく検出できず、ほとんどのレコードが 1 手だけの対局として分割される。この兆候が
あるときは起動時に警告を表示する。

### tournament の out-dir を開く

```bash
cargo run -p tools --release --features kifu-player --bin kifu_player -- \
  --tournament-dir runs/selfplay/<out-dir>
```

out-dir 配下の `*-vs-*.jsonl`（`tournament` が出力するペアファイル）を横断して 1 つの
対局リストにまとめる。対局データを含まない付随ファイルは自動的に除外する。

### CSA を開く

```bash
# 単一ファイル
cargo run -p tools --release --features kifu-player --bin kifu_player -- \
  --csa runs/csa_match/game.csa

# ディレクトリ（配下の *.csa をサブディレクトリまで再帰して横断）
cargo run -p tools --release --features kifu-player --bin kifu_player -- \
  --csa runs/csa_match
```

`--csa` には CSA 棋譜（1 ファイル = 1 対局）を渡す。ディレクトリを指定すると
`YYYY/MM/DD/*.csa` のようなネストも再帰して集め、パス順に並べる。対局ラベルには
プレイヤー名を使う。

- **勝敗**は棋譜末尾の終局（投了・入玉宣言など）から判定する。終局が記録されていない
  （中断・未完の）ファイルは「勝敗不明」として扱う。
- **評価値**は棋譜に埋め込まれたエンジンのコメントから読み取る。コメントの無い手・対局は
  評価値なし（グラフに打点しない）。片方のエンジンしか評価値を書いていない対局では、
  その側の手だけが打点される。

## 画面構成

- 左: 対局一覧（`/` で検索・絞り込み、`s` で並べ替え。タイトルに現在の並び順を表示）
- 中央: 盤面。先手の駒は黄、後手の駒はシアンで色分けし、上端に筋（９〜１）、右端に段
  （一〜九）のラベルを表示する。成り駒は一文字で表す（成香=杏 / 成桂=圭 / 成銀=全 /
  と / 馬 / 龍）。**現在の手を指し終えた後の局面**を表示し、最終手の移動先と移動元を
  緑の背景＋太字でハイライトする。手番・持駒・王手も指了後を反映する（「王手」＝最終手が
  王手だったこと）。投了・時間切れなど盤上を実際には動かさない手では、直前の局面を
  そのまま表示する。
- 右: 指し手一覧。棋譜風ラベルと各手の注釈（評価値・`depth=`・`seldepth=`・`nodes=`・
  `nps=`・経過）を並べる。評価値・詰みは評価値グラフと同じ**先手基準**（＋先手優勢／
  －後手優勢）で表示する。手数は絶対手数なので、定跡途中から始まる対局でも正しい手数から
  始まる。先頭の手が記録から欠落している場合は、その手の前に `⋯N手欠落⋯` と表示する。
  現在の手をハイライトする。パネル幅に収まらない注釈は末尾が切れる。
- 評価値グラフ: 先手から見た評価値（**プラス=先手優勢、マイナス=後手優勢**）を、着手側の
  色（先手=黄、後手=シアン）で塗り分けて表示する。先後に別エンジンが付く対局では評価値の
  スケールがエンジンごとに異なりうるので、グラフの振れを単純な形勢差と読みすぎないこと。
  評価値の無い手は打点しない。
- 下部: ステータスバー。キーバインドのヘルプと、対局の読み込みエラー等のメッセージを表示する。

対局データが 0 手（エンジン起動失敗等のエラー対局）の場合は、盤面・指し手ペインにその旨を
表示する。

## 検索・絞り込み（`/`）

`field:value` の構文でフィールドを指定して絞り込む。入力中は入力欄に主なフィールドの
ヒントと現在の一致件数を表示する。

| 構文 | 絞り込み対象 | 一致方式 |
|------|------|------|
| `pair:<n>` | ペア番号（JSONL のみ） | 完全一致 |
| `slot:<n>` | スロット番号（JSONL のみ） | 完全一致 |
| `startpos:<n>` | 開始局面番号（JSONL のみ） | 完全一致 |
| `id:<n>` | 対局 ID（JSONL のみ、ペアファイル内のローカル連番） | 完全一致 |
| `outcome:<kw>` | 勝敗キーワード（`black_win`/`white_win`/`draw`/`error`） | 部分一致 |
| `label:<text>` | 対局ラベル | 部分一致 |
| `winner:sente\|gote` | 勝者側（`black`/`white` も可） | 完全一致 |
| `len:>N` / `len:<N` / `len:N` | 手数 | 比較 |
| `swing:>N` / `swing:<N` / `swing:N` | 評価値の振れ幅（cp） | 比較 |
| `reversal` | 両者が 300cp 以上優勢になった局面がある（形勢逆転） | 述語 |
| `decisive` | 勝敗が付いた（引き分け・エラー・不明でない） | 述語 |
| `sfen:<SFEN>` | 局面本体（各手の着手前局面） | 完全一致（手数フィールドを除く、`Enter` で逐次スキャン） |

`winner`/`len`/`swing`/`reversal`/`decisive` は対局の評価値と手数から判定するので、
PSV/JSONL/CSA どの入力でも使える。評価値の無い対局は `swing:`/`reversal` にヒットしない。

`id:<n>` は `pair:`/`slot:`/`startpos:` と組み合わせられない。対局 ID はペアファイル内の
ローカル連番で out-dir 全体では一意でないため、同じ ID の対局が複数のエンジンペアにあると
それら全部にヒットする。対局を一意に絞りたいときは、対局ラベルや `pair:`/`slot:`/`startpos:`
で絞ってから `j`/`k` で辿る。

prefix を付けずに**数字のみ**を入力すると、数値フィールド（ペア番号・スロット番号・
開始局面番号・対局 ID）の完全一致だけを見る（対局ラベルの部分一致は見ない）。これにより、
エンジンラベルに数字を含むデータ（例: `vol4B_raw`）でペア番号 `4` を探しても、ラベル中の
`4` への部分一致でノイズが出ない。数字以外の自由文字列は、対局ラベルの部分一致または
勝敗キーワードの部分一致で絞り込む。

### 局面検索（`sfen:<SFEN>`）

他のフィルタが索引済みのメタ情報（勝敗・手数・評価値）だけを見て入力と同時に絞り込むのに
対し、`sfen:` は各手の局面本体を照合するため、**`Enter` を押したときに全対局を逐次スキャン**
する。1 対局ずつ棋譜を読み込んでは照合し捨てるので、対局数が多くてもメモリは増えない
（索引はメタ情報だけを保持したまま）。スキャン中はステータスバーに進捗（走査済み / 総数 /
一致件数）を表示し、`Esc` または `q` で中断できる（中断すると絞り込みは実行前のまま）。

照合は末尾の**手数フィールドを無視**した「盤面・手番・持駒」の完全一致で、同じ局面が対局中の
どの手数で現れても一致する。SFEN は大文字＝先手駒・小文字＝後手駒で意味が変わるため、
このフィールドだけは大文字・小文字を区別する（他フィールドの小文字化は適用しない）。盤面を
表示中の局面はそのままコピーして貼り付けられる。各手の**着手前**局面を照合するので、最終手を
指し終えた後の局面だけは対象に含まれない。

## 並べ替え（`s`）

`s` を押すたびに次の順序へ循環する（絞り込み後のリストに適用、同順のものは元の順序を
保つ安定ソート）。評価値による並べ替えは降順で、評価値の無い対局は末尾へ寄せる。

1. 発見順（デフォルト）
2. 勝敗別（エラー→先手勝ち→後手勝ち→引き分け→不明）
3. 対局長（手数の降順）
4. 決着の大きさ（最終評価値の絶対値の降順）
5. 評価値の振れ幅（降順）

## 評価値急変ジャンプ（`n` / `N`）

`n` で次、`N` で前の「直前の評価値付きの手との評価値差が 200cp を超える手」へジャンプする。
評価値グラフで振れの大きい局面へ手動スクロールせずに辿り着ける。

## キーバインド

| キー | 動作 |
|------|------|
| `h` / `←` | 1手戻す |
| `l` / `→` | 1手進める |
| `j` / `↓` | 次の対局（絞り込み後のリスト内） |
| `k` / `↑` | 前の対局 |
| `n` | 次の評価値急変手へジャンプ |
| `N` | 前の評価値急変手へジャンプ |
| `s` | 対局リストの並べ替えを切り替え |
| `/` | 検索・絞り込み入力開始（`Enter`/`Esc` で終了、`Esc` は絞り込みもクリア） |
| `?` | キーバインド一覧のヘルプを表示・終了（表示中は任意のキーで閉じる） |
| `q` / `Esc` | 終了（ヘルプ表示中は閉じるだけ） |

## スコープ外

- 実行中の tournament のライブ追従（オフライン解析専用）
- セッションをまたいだ「最後に見ていた対局」の記憶
- 棋譜ファイルへの書き込み・KIF/CSA へのエクスポート（`jsonl_to_kif` 等の既存ツールで代替）
- 評価値グラフの Y 軸の自動スケール（現状は固定範囲）
